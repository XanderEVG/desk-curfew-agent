# desk-curfew-agent

Агент **desk-curfew** для Windows. Устанавливается на детские компьютеры.

Получает команды блокировки/разблокировки через MQTT, показывает
полноэкранное окно блокировки, отправляет heartbeat и статус на сервер.

Агент **не принимает решений** — он только исполнитель. Вся логика
расписания и лимитов находится на сервере (desk-curfew-server).

## Архитектура

Обмен между агентами и сервером идёт **только через MQTT**.

## Возможности

- Подключение к MQTT-брокеру по SSL
- Heartbeat каждые 30 секунд
- Retained-статус (онлайн/оффлайн, заблокирован/разблокирован)
- Last Will — сервер узнаёт, если агент упал
- Полноэкранное окно блокировки (PyQt6)
- Grace period: предупреждения за 5 мин, 1 мин, 10 сек до блокировки
- Команды: lock_now, lock_in, unlock, shutdown_in, add_time
- Логирование в файл
- Автозапуск при входе пользователя

## MQTT-топики

| Топик | Направление | Назначение |
|---|---|---|
| `{pc}/cmd` | сервер → агент | Команды (lock, unlock, shutdown) |
| `{pc}/status` | агент → сервер | Retained-статус агента |
| `{pc}/event` | агент → сервер | События (locked, unlocked, warning) |
| `{pc}/hb` | агент → сервер | Heartbeat каждые 30 сек |

Где `{pc}` — `evgeny_pc` или `andrey_pc`.

## Команды

| Команда        | Параметры                      | Описание                                     |
|----------------|--------------------------------|----------------------------------------------|
| lock_now       | reason                         | Немедленная блокировка                       |
| lock_in        | delay_seconds, reason, message | Блокировка через N секунд с предупреждениями |
| unlock         | reason                         | Разблокировка                                |
| shutdown_in    | delay_seconds, message         | Выключение через N секунд                    |
| add_time       | minutes                        | Добавить время (сброс таймера блокировки)    |
| status_request | —                              | Запросить текущий статус                     |

## Сборка

### 1. Конфиг
```bash
cp config.yaml.example config.yaml
```

### 2.  Запуск
```bash
pip install -r requirements.txt
build.bat
```
Результат: dist\DeskCurfewAgent.exe

## Установка на детский ПК

1. Скопировать DeskCurfewAgent.exe и config.yaml в C:\Program Files\DeskCurfew\
2. Запустить install_task.bat от имени администратора. 
   
    Это создаст задачу в Планировщике Windows:
      - Триггер: при входе в систему
      - Действие: запуск DeskCurfewAgent.exe
      - Выполнять с наивысшими правами

3. Перезагрузить компьютер, проверить что агент запустился.

## Ограничения (текущий этап)

- Агент работает в пользовательской сессии, не как служба.
- Ребёнок с правами администратора может завершить процесс через Диспетчер задач.
- Ctrl+Alt+Del не блокируется (ограничение Windows).
- Автозапуск через Планировщик можно отключить, зная где искать.
- Эти ограничения осознанные. Защита будет усиливаться по мере необходимости (микроагент-сторож, групповые политики и т.д.).
